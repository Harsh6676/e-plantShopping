# Paradise Nursery

## Project Name
e-plantShopping

## Project Description
Paradise Nursery is a React-based online plant shopping application where users can browse plants, view plant details, add plants to a shopping cart, update quantities, remove products, and calculate the total cart amount.

## Features
- Landing page with Paradise Nursery branding
- Plant product listing
- Multiple plant categories
- Add to Cart functionality
- Shopping cart
- Increase and decrease product quantity
- Remove items from cart
- Total cart amount calculation
- Continue Shopping
- Checkout button

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite
